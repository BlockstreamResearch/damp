# Historical audit-cost fixtures

These measurements belong to preliminary arithmetic, cost, and amount-range
experiments. They are not the deployed protocol specification or evidence of
production security. The online-approval experiments represent an abandoned
design; current transfers do not require issuer approval.

The current implementation and network evidence are described in
[the v0.2 documentation](../pgc-e2e/README.md).

The JSON fixtures are retained for comparison with their corresponding Rust
examples. `scripts/validate-pgc-autonomous.sh` compares four autonomous cost
outputs byte-for-byte and checks example lint. Historical review manifests and
process notes have been removed; no current or past review verdict follows
from those fixture comparisons.
