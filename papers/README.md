# Papers

- [`damp/`](damp/) is the canonical existing DAMP protocol paper about regulated
  Liquid assets and Simplicity covenants.
- [`pgc/`](pgc/) is the distinct PGC equal-value paper about the project's
  host-bound twisted-ElGamal proof of concept, its evidence, and its integration
  limits.

Run `make` in this directory to build both manuscripts. Each subdirectory keeps
generated LaTeX files and its PDF under `out/`.
