# Native confidential audit proofs

This standalone manuscript describes a proof linking a native Elements value
commitment to an issuer audit handle. It covers Simplicity verification,
authenticated recovery data and bounded discrete-log recovery.

The appendix presents a Simplicity implementation of the checks discussed in
the paper, with numbered `.simf` listings and mathematical mappings.

Run `make -C papers/pgc` from the repository root to create `out/main.pdf` here.
